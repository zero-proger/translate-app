# Переводчик PDF-книг (PySide6)

## Что нового в этой версии

### Панель «Оформление» перенесена над областью просмотра

Как в обычных текстовых редакторах (Word / LibreOffice): сверху панель
форматирования, под ней — сам документ. Правая панель разгружена и теперь
отвечает только за работу с блоками и строками.

**Новая структура окна:**

```

┌──────────┬──────────────────────────────────────┬──────────────────┐
│          │  ┌─ Оформление ───────────────────┐  │ Блоки на странице│
│ Страницы │  │ Шрифт [▾] Размер [ ] … [ЛЦШП]   │  │ [list]           │
│ ┌──────┐ │  │ [✓] Уменьшать … [✓] Сжимать …   │  │ [◀ Блок][Блок ▶] │
│ │ 1    │ │  │ [К строке][К блоку] …           │  ├──────────────────┤
│ │ 2    │ │  └────────────────────────────────┘  │ Строки в блоке   │
│ │ 3    │ │                                      │ [list]           │
│ │ …    │ │           PageView                   │ [◀ Стр][Стр ▶]   │
│ └──────┘ │                                      │ [✓] Автоперевод  │
│          │                                      ├──────────────────┤
│          │                                      │ [Перевести блок] │
│          │                                      │ [Перевести строку]│
│          │                                      ├──────────────────┤
│          │                                      │ Оригинал [text]  │
│          │                                      │ Перевод  [text]  │
└──────────┴──────────────────────────────────────┴──────────────────┘

```

**Панель «Оформление»** (сверху над просмотром, три строки):

1. Шрифт, размер, интервал, выравнивание (4 кнопки Л/Ц/Ш/П), жирный, курсив.
2. Уменьшать шрифт при переполнении, сжимать текст по ширине + мин. %, компактная вёрстка блока.
3. Кнопки «К строке», «К блоку», «К странице», «Ко всей книге», «Только шрифт — ко всему документу», «Сбросить оформление».

**Правая панель** — только:

* Блоки на странице (список + навигация ◀ ▶);
* Строки в блоке (список + навигация + автоперевод);
* Кнопки «Перевести блок» / «Перевести строку»;
* Оригинал;
* Перевод (редактируемое поле).

## Что нужно обновить

Скопируйте два файла с заменой:

* `app/main_window.py` — панель форматирования переехала сюда
* `verify_install.py` — обновлён список ключевых методов

Остальные файлы (`app/main_window_files.py`, `app/main_window_edit.py`,
`app/main_window_translate.py`, `app/project.py`, `app/translator.py`,
`main.py`, `requirements.txt`) **не менялись**.

Затем:

```powershell
# Windows PowerShell
Get-ChildItem -Recurse -Filter "__pycache__" | Remove-Item -Recurse -Force
Get-ChildItem -Recurse -Filter "*.pyc" | Remove-Item -Force
python verify_install.py
python main.py
```

```
# Linux / macOS
find . -name "__pycache__" -type d -exec rm -rf {} +
find . -name "*.pyc" -delete
python verify_install.py
python main.py
```

## Как работает новая панель

- Панель **независима от PageView** — она сидит в `QVBoxLayout` над просмотром,
поэтому не сжимается и не растягивается вместе с документом.
- При ресайзе окна она остаётся сверху, а `PageView` забирает всё свободное
место (`stretch=1`).
- Все контролы имеют те же имена атрибутов (`font_combo`, `size_spin`,
`align_buttons`, `condense_check`, `apply_line_button` и т. д.) — логика
`_apply_format`, `_sync_controls`, `_current_align`, `apply_font_only_to_all`
продолжает работать без изменений.
- Кнопки Л/Ц/Ш/П по-прежнему `checkable` в эксклюзивной `QButtonGroup`:
активна ровно одна, выбранная залита синим.

## Остальной функционал

Всё сохранено:

- кнопка **«Остановить»** в тулбаре — прерывает перевод между фрагментами;
- **«Файл → Сохранить / Открыть проект…»** (`Ctrl+Shift+S` / `Ctrl+Shift+O`) —
`.pdftr` с путём к PDF, текущей страницей, настройками перевода, всеми
переводами и оформлением;
- **«Только шрифт — ко всему документу»** — на новой панели, третья строка;
- узкий шрифт по умолчанию, горизонтальное сжатие, компактная вёрстка,
редактирование текста прямо на странице.
