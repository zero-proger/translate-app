## main.py — точка входа

| Функция | Описание |
|---|---|
| `main()` | Создаёт `QApplication`, применяет глобальный CSS из файла `StyleSheet`, показывает `MainWindow` и запускает цикл событий Qt. |
| патч `ctranslate2.Translator.__init__` | При наличии `ctranslate2` подставляет потоки перевода (`intra_threads`) из переменной окружения `ARGOS_THREADS` или по числу ядер CPU, чтобы офлайн-перевод использовал все ядра. |

## app/models.py — модель данных

Три dataclass-а, описывающие документ как дерево «страница → блок → строка».

### `TextLine` — одна строка текста внутри блока

Хранит геометрию (`bbox`, `origin`), исходный текст `original`, перевод
`translated`, базовые параметры оригинала (`base_size`, `base_color`,
`base_bold`, `base_italic`, `base_font`) и переопределения оформления
(`font_family`, `font_size`, `bold`, `italic`, `align`; `None` = наследовать).

| Метод | Описание |
|---|---|
| `eff_text()` | Возвращает перевод, если он непустой, иначе оригинал — то, что реально рисуется на странице. |
| `eff_family()` | Эффективное семейство шрифта (переопределение или значение по умолчанию). |
| `eff_size()` | Эффективный кегль (переопределение или размер из оригинального PDF). |
| `eff_bold()` / `eff_italic()` | Эффективные признаки жирного/курсивного начертания. |
| `eff_align()` | Эффективное выравнивание (`left` / `center` / `justify` / `right`). |

### `TextBlock` — блок (абзац)

Список строк `lines`, геометрия `bbox`, тип (`text`/`image`), привязка к
именованному стилю `style_name`, флаги компактной вёрстки и ручной геометрии
(`manual_bbox`, `x_scale`, `y_scale`).

### `PageData` — страница

Номер страницы, размер, список блоков `blocks`.

## app/extractor.py — извлечение текста из PDF

Единственная публичная функция; всё остальное — внутренние эвристики.

| Функция | Описание |
|---|---|
| `extract_document(path, preferred_family=None)` | Открывает PDF через PyMuPDF, для каждой страницы извлекает текстовые блоки/строки/спанов, собирает дерево `PageData[]`: кегль, цвет, начертание, координаты, предполагаемое выравнивание. Возвращает `(pages, doc)`. |
| `_line_text(line)` | Склеивает текст спанов одной строки. |
| `_join_lines(lines)` | Объединение строк в текст блока через пробел. |
| `_line_bbox(line)` | Прямоугольник строки по координатам спанов. |
| `_combine_bboxes(bboxes)` | Объединяет список прямоугольников в один охватывающий. |
| `_dominant_span(line)` | Самый «весомый» спан строки — источник размера/шрифта/цвета. |
| `_is_list_item(text)` | Признак того, что строка начинается как пункт списка (маркер, тире, цифра с точкой). |
| `_should_split_after(prev, cur, median_advance)` | Эвристика: принадлежит ли строка предыдущему абзацу или началу нового (по интерлиньяжу, отступу, знакам препинания, спискам). |
| `_split_block_into_groups(lines_raw)` | Режет «сырой» блок PyMuPDF на группы-абзацы с помощью `_should_split_after`. |
| `_estimate_spacing(lines, size)` | Оценка межстрочного интервала в k-em для последующего воспроизведения. |
| `_guess_align(lines, bbox, page_width)` | Определяет выравнивание блока (центр/право/по ширине/слева) по положению строк относительно границ блока и страницы. |
| `_color_tuple(int_color)` | Конвертация целого цвета PyMuPDF в кортеж RGB 0..1. |
| `_span_info(spans)` | Извлечение характеристик спана: размер, шрифт, флаги bold/italic, цвет. |
| `_pick_family(original_font, preferred)` | Выбор семейства-замены для исходного (часто кириллического) шрифта PDF. |

## app/page_view.py — просмотр и редактирование страницы

### Модульные функции

| Функция | Описание |
|---|---|
| `_normalize_font_name(name)` | Приведение имени системного шрифта к каноническому виду (регистр, суффиксы). |
| `family_name_for(family_key)` | Подбор конкретного системного шрифта под логическое семейство (serif/sans/…) с учётом bold/italic. |
| `register_pdf_fonts(doc)` | Сканирует PDF, регистрирует его встроенные шрифты в Qt (`QFontDatabase.addApplicationFont`) и возвращает карту «имя файла → имя Qt-шрифта», чтобы превью совпадало с оригиналом. |

### Класс `EditableLineItem(QGraphicsTextItem)` — строка прямо на холсте

| Метод | Описание |
|---|---|
| `__init__(view, block, line_index)` | Создаёт редактируемый элемент, привязанный к конкретной строке модели. |
| `line()` | Актуальный объект `TextLine` (или `None`, если данные изменились). |
| `refresh()` | Перерисовывает элемент: шрифт, размер, цвет, позиционирование по bbox, перенос по ширине блока, подсветка выбранной строки, тултип. |
| `_update_tooltip()` | Формирует всплывающую подсказку с параметрами строки. |
| `mousePressEvent` | Одиночный клик — выделение блока/строки в списке редактора. |
| `mouseDoubleClickEvent` | Двойной клик — переход в режим правки текста прямо на странице. |
| `focusOutEvent` | Потеря фокуса — фиксация отредактированного текста в модели. |
| `keyPressEvent` | Enter/Esc завершают редактирование; обычные символы обрабатывает Qt. |

### Класс `PageView(QGraphicsView)` — холст страницы

| Метод | Описание |
|---|---|
| `zoom_factor()` | Текущий масштаб. |
| `set_document(src_doc)` | Запоминает исходный PDF-документ. |
| `set_page(src_doc, page_data, zoom)` | Показывает страницу: фон + слой редактируемых строк. |
| `set_zoom(zoom)` | Устанавливает масштаб просмотра. |
| `invalidate_background()` | Сбрасывает кэш растрового фона (при изменении документа). |
| `_get_background()` | Рендерит и кэширует pixmap страницы; при пустых переводах — оригинал целиком, иначе — фон без переведённых блоков (redaction). |
| `_rebuild()` | Полная перестройка сцены: фон + `EditableLineItem` для всех непустых строк. |
| `refresh_block(block_index)` | Точечное обновление элементов одного блока. |
| `refresh_all()` | Обновление всех элементов страницы. |
| `highlight_block(block_index, line_index=None)` | Визуальная подсветка выбранного блока/строки. |

## app/builder.py — сборка выходного PDF

Рисование переведённого текста «с нуля» поверх вычищенных оригинальных блоков.

| Функция | Описание |
|---|---|
| `get_font(family, bold, italic)` | Кэш объектов `fitz.Font`: подбор TTF по семейству и начертанию (см. `ttf/FONTS.md`). |
| `wrap_text(text, font, size, max_width)` | Разбивка текста на строки по ширине блока с измерением реальной ширины глифов. |
| `_apply_redactions(page)` | Применяет redaction-аннотации: физически удаляет оригинальный текст из области блока, сохраняя картинки и фон. |
| `_draw_text_line(page, text, rect, ...)` | Рисует одну строку заданным шрифтом/размером/цветом с горизонтальным сжатием (`sx`), если текст не влезает. |
| `_best_single_line_sx(...)` | Подбирает максимальный коэффициент сжатия ≤ 1, при котором строка помещается в одну линию. |
| `draw_line(page, line)` | Низкоуровневый вывод одной `TextLine` в её bbox с учётом стиля, выравнивания и компактной вёрстки. |
| `draw_block_as_whole(page, block, ...)` | Раскладывает весь блок целиком: переносы, межстрочный интервал, выравнивание (в т.ч. justify), компактная вёрстка, вертикальное сжатие при переполнении. |
| `build_page_background(src_doc, page_data)` | Копия страницы источника, из которой удалён только текст (для слоёв предпросмотра). |
| `build_page_doc(src_doc, page_data)` | Полностью собранная страница: redaction оригиналов + отрисовка всех блоков переводов. |
| `export_pdf(src_doc, pages, out_path, ...)` | Проходит по всем страницам, собирает новый PDF и сохраняет в `out_path`. Используется и для превью отдельной страницы, и для финального экспорта всей книги. |

## app/translator_engines.py — движки перевода

Все бэкенды имеют единый интерфейс `translate(text) -> str`.

### `GoogleFreeBackend` — онлайн (deep-translator, Google, бесплатно)

| Метод | Описание |
|---|---|
| `__init__(source, target, delay_ms)` | Настраивает переводчик и паузу между запросами (анти-троттлинг). |
| `translate(text)` | Публичный интерфейс: режет длинный текст на чанки, переводит, склеивает. |
| `_translate_chunk(chunk)` | Один запрос к API с защитой чисел, ограничителем частоты и повторными попытками при троттлинге. |

### `ArgosBackend` — офлайн на CPU (Argostranslate / CTranslate2)

| Метод | Описание |
|---|---|
| `__init__(source, target)` | Ищет установленную языковую пару, иначе — понятная ошибка со ссылкой на диалог настроек. |
| `_plain(text)` | Вызов движка на чистом тексте без разметки. |
| `_plain_multi(text)` | Построчный перевод с сохранением переносов. |
| `_segment_translate(text)` | Перевод по предложениям (spacy-сегментация) — стабильнее на абзацах. |
| `translate(text)` | Диспетчер: выбирает стратегию (весь текст / построчно / по предложениям) по длине и структуре. |

### `LocalGpuBackend` — локальная NMT-модель (transformers, GPU/CPU)

| Функция/метод | Описание |
|---|---|
| `get_gpu_info()` | Строка с описанием доступных устройств (CUDA/MPS/CPU) — показывается в настройках. |
| `_resolve_device(requested)` | Выбор устройства: auto/cuda/mps/cpu с деградацией, если запрошенного нет. |
| `_load_local_model(model_name, device)` | Кэшированная загрузка encoder-decoder модели (Helsinki-NLP и подобных). |
| `__init__(...)` | Загрузка модели и токенизатора, проверка поддерживаемой пары языков. |
| `_translate_batch(texts)` | Пакетная генерация — быстрый путь для больших объёмов. |
| `_raw_translate(text)` | Перевод одного фрагмента. |
| `_segment_translate(text)` | Перевод по предложениям с окном ≤128 токенов. |
| `translate(text)` | Публичный интерфейс (сегментация + очистка результата). |
| `translate_many(texts)` | Массовый перевод батчами (используется воркером для ускорения). |

### `ChatLlmBackend` — локальный чат-LM (Qwen/Mistral и т. п.)

| Метод | Описание |
|---|---|
| `__init__(...)` | Загрузка causal-модели в нужном dtype/устройстве, выбор формата чата. |
| `_messages(text)` | Сборка промпта: системная инструкция «переведи буквально, сохраняй форматирование» + текст. |
| `_clean(text)` | Отсечение хвостов модели («Оригинал:», маркеров остановки), удаление мета-комментариев. |
| `_build_inputs(text)` | Токенизация chat-template в тензоры. |
| `_split_for_translation(text, max_chars)` | Нарезка слишком длинного текста по границам предложений перед генерацией. |
| `_generate_once(text)` | Один проход `model.generate` с эвристикой длины вывода. |
| `_raw_multi(text)` | Перевод многострочного текста (сохраняя структуру). |
| `_segment_translate(text)` | Перевод по смысловым сегментам. |
| `translate(text)` | Публичный интерфейс. |

## app/project.py — сохранение/загрузка проекта

Формат `.pdftr` — JSON: путь к PDF + все переводы + оформление + настройки.

| Функция | Описание |
|---|---|
| `_styles_to_plain(styles)` | Сериализация библиотеки стилей окна. |
| `relpath(path, base)` / `abspath(path, base)` | Путь к PDF хранится относительно проекта — переносимость между машинами. |
| `_line_to_dict(line)` / `_block_to_dict(block)` / `_page_to_dict(page)` | Поблочная сериализация дерева документа (только дельты: переводы и переопределения стиля). |
| `_normalize_fonts_in_settings(settings, transform)` | Приведение имён шрифтов в сохранённых настройках при загрузке. |
| `save_project(path, pdf_path, pages, settings, styles)` | Запись проекта в файл. |
